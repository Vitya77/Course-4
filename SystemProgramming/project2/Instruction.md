# ДОКУМЕНТАЦІЯ ДО БІБЛІОТЕКИ ДИНАМІЧНОГО ЗВ'ЯЗКУ (DLL) "MathStatLib"

## 1. ЗАГАЛЬНІ ВІДОМОСТІ ТА ОБҐРУНТУВАННЯ ТЕМИ
**Тема бібліотеки:** Статистичний аналіз та первинна обробка числових даних.
**Призначення:** Бібліотека призначена для автоматизації розрахунків основних статистичних показників масивів даних. Вона може бути використана в академічних дослідженнях, економічних розрахунках або при розробці аналітичного ПЗ.
**Реалізація:** Бібліотека написана мовою C (стандарт C99), скомпільована у машинний код (x64) для забезпечення високої швидкодії та можливості виклику з різних мов програмування (C++, Python, C#, Java тощо).

---

## 2. СКЛАД БІБЛІОТЕКИ (ФАЙЛИ)
*   **mathstat.dll** — основний файл бібліотеки з реалізацією функцій у машинному коді.
*   **mathstat.lib** — файл імпорту (статична бібліотека зв'язку) для компіляторів MSVC.
*   **mathstat.h** — заголовний файл із прототипами функцій для мови C/C++.

---

## 3. ФУНКЦІОНАЛЬНО-ПАРАМЕТРИЧНИЙ ОПИС ФУНКЦІЙ

Нижче наведено детальний опис кожної з 8 реалізованих функцій.

### 3.1. Функція `ms_sum`
*   **Прототип:** `double ms_sum(const double* data, int n);`
*   **Призначення:** Розрахунок арифметичної суми елементів масиву.
*   **Вхідні параметри:**
    *   `data` (const double*): вказівник на масив дійсних чисел.
    *   `n` (int): кількість елементів у масиві.
*   **Результат:** Повертає значення суми (double). Якщо масив порожній, повертає 0.0.

### 3.2. Функція `ms_mean`
*   **Прототип:** `double ms_mean(const double* data, int n);`
*   **Призначення:** Обчислення середнього арифметичного значення вибірки.
*   **Вхідні параметри:** `data` (масив), `n` (кількість).
*   **Результат:** Повертає середнє значення (double).

### 3.3. Функція `ms_variance`
*   **Прототип:** `double ms_variance(const double* data, int n);`
*   **Призначення:** Розрахунок вибіркової дисперсії (міри розсіювання даних).
*   **Вхідні параметри:** `data` (масив), `n` (кількість). Потребує `n > 1`.
*   **Результат:** Значення дисперсії (double).

### 3.4. Функція `ms_std_dev`
*   **Прототип:** `double ms_std_dev(const double* data, int n);`
*   **Призначення:** Обчислення середньоквадратичного відхилення (стандартне відхилення).
*   **Вхідні параметри:** `data` (масив), `n` (кількість).
*   **Результат:** Значення std_dev (double). Обчислюється як корінь квадратний з дисперсії.

### 3.5. Функція `ms_min`
*   **Прототип:** `double ms_min(const double* data, int n);`
*   **Призначення:** Пошук мінімального значення у наборі даних.
*   **Вхідні параметри:** `data` (масив), `n` (кількість).
*   **Результат:** Мінімальне число (double).

### 3.6. Функція `ms_max`
*   **Прототип:** `double ms_max(const double* data, int n);`
*   **Призначення:** Пошук максимального значення у наборі даних.
*   **Вхідні параметри:** `data` (масив), `n` (кількість).
*   **Результат:** Максимальне число (double).

### 3.7. Функція `ms_sort`
*   **Прототип:** `void ms_sort(double* data, int n);`
*   **Призначення:** Сортування масиву за зростанням для підготовки до розрахунку медіани.
*   **Алгоритм:** Метод "бульбашки" (in-place).
*   **Вхідні параметри:** `data` (масив), `n` (кількість).
*   **Результат:** Не повертає значення, але змінює порядок елементів безпосередньо у масиві.

### 3.8. Функція `ms_median`
*   **Прототип:** `double ms_median(double* data, int n);`
*   **Призначення:** Розрахунок медіани (значення, що розділяє вибірку навпіл).
*   **Особливість:** Функція автоматично викликає `ms_sort` перед розрахунком.
*   **Результат:** Медіанне значення (double).

## 4. ПРИКЛАД ВИКОРИСТАННЯ (PYTHON)
```python
import ctypes
lib = ctypes.CDLL("./mathstat.dll")
lib.ms_mean.argtypes = [ctypes.POINTER(ctypes.c_double), ctypes.c_int]
lib.ms_mean.restype = ctypes.c_double

data = (ctypes.c_double * 3)(10.0, 20.0, 30.0)
result = lib.ms_mean(data, 3)
print(f"Mean: {result}")
```
